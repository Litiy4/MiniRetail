# MiniRetail

Учебно-портфельный проект: мини-конфигурация оперативного учёта торговли на платформе 1С:Предприятие 8.3 (учебная версия, управляемые формы).

Проект создаётся с нуля как сквозной полигон: от справочников и проведения документов — до HTTP-сервисов, автотестов и интеграции с Clickhouse/Python («мини-Imprice»: выгрузка продаж → расчёт рекомендованных цен → загрузка обратно).

## Структура репозитория

```
MiniRetail/
├── README.md       — карта проекта (этот файл)
├── docs/
│   └── issues/     — постановки задач с критериями приёмки
└── src/            — XML-выгрузка конфигурации (пакетный режим конфигуратора)
```

## Стек

- 1С:Предприятие 8.3 (учебная версия), управляемые формы
- Конфигуратор → (план) 1C:EDT
- git + GitHub
- (план) YAxUnit — автотесты
- (план) Python + Clickhouse — аналитический контур
