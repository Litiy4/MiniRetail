## Контекст

MiniRetail начинает ядро оперативного учёта торговли. Первый кирпич — справочник товаров
(«Номенклатура») и неизменяемый список единиц измерения. Это «словари» системы: на них
будут ссылаться все будущие документы (Поступление, Реализация, Перемещение).

## Требования

1. Перечисление `ЕдиницыИзмерения` со значениями: `шт`, `кг`, `л`, `упаковка`.
2. Справочник `Номенклатура`:
   - длина наименования — 100 символов;
   - реквизит `Артикул` — Строка(50);
   - реквизит `ЕдиницаИзмерения` — тип `ПеречислениеСсылка.ЕдиницыИзмерения`;
   - формы — автогенерируемые (на этом занятии отдельные формы не создаём).

## Критерии приёмки

- [x] В дереве метаданных есть перечисление `ЕдиницыИзмерения` с 4 значениями
- [x] Справочник `Номенклатура` содержит реквизиты `Артикул` и `ЕдиницаИзмерения` с типами по ТЗ
- [x] В режиме Предприятие элемент создаётся; артикул сохраняется после записи; единица выбирается из выпадающего списка
- [x] Конфигурация выгружена в `src/` и закоммичена (`feat: справочник Номенклатура и перечисление ЕдиницыИзмерения`)

## Порядок работы (шпаргалка исполнителю)

1. Запуск 1С → база `MiniRetail` → кнопка **Конфигуратор**.
2. Меню **Конфигурация → Открыть конфигурацию** — слева появится дерево объектов.
3. Правый клик на ветке **Перечисления → Добавить** → имя `ЕдиницыИзмерения` → вкладка
   **Данные** → добавить 4 значения.
4. Правый клик на ветке **Справочники → Добавить** → имя `Номенклатура` → вкладка **Данные**:
   длина наименования 100 → раздел **Реквизиты** → добавить `Артикул` и `ЕдиницаИзмерения`.
5. **Ctrl+S** → на вопрос «Обновить конфигурацию базы данных?» ответить **Да** (это F7 —
   применить изменения к базе).
6. **F5** (Отладка → Начать отладку) — откроется режим Предприятие → Номенклатура →
   создать 5 разных товаров с артикулами и единицами.
7. Сообщить постановщику «готово» — он выгрузит конфигурацию и примет работу.
