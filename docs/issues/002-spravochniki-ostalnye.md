# Issue 002: Справочники «Контрагенты», «Склады», «Магазины»

**Статус:** в работе
**Спринт:** Фаза 1, занятие 2
**Исполнитель:** Palit (Litiy4)

## Контекст

Расширяем «словари» MiniRetail до полного набора для оперативного учёта:
- **Контрагенты** — участники сделок (поставщики и покупатели). Тренируем **иерархию** (группы и элементы).
- **Склады** — места хранения. Минимальный справочник.
- **Магазины** — точки продаж. Тренируем **ссылочные связи между справочниками**: у магазина есть склад.

## Требования

1. Справочник `Контрагенты`:
   - иерархия **групп и элементов**;
   - длина наименования 100;
   - реквизит `ИНН` — Строка(12);
   - реквизит `Телефон` — Строка(20).
2. Справочник `Склады`: без иерархии, длина наименования 100, без реквизитов.
3. Справочник `Магазины`:
   - реквизит `Адрес` — Строка(200);
   - реквизит `Склад` — тип `СправочникСсылка.Склады`.
4. Формы — автогенерируемые.

## Критерии приёмки

- [ ] `src/Catalogs/Контрагенты.xml`: `Hierarchical=true`, реквизиты `ИНН` (Строка 12) и `Телефон` (Строка 20)
- [ ] `src/Catalogs/Склады.xml` существует
- [ ] `src/Catalogs/Магазины.xml`: реквизит `Адрес` (Строка 200), реквизит `Склад` типа `CatalogRef.Склады`
- [ ] В Предприятии: в Контрагентах созданы группы «Поставщики» и «Покупатели» (в каждой 1–2 элемента с ИНН и телефоном); 2 склада; 2 магазина со ссылками на склады
- [ ] Конфигурация выгружена в `src/`, коммит `feat: справочники Контрагенты, Склады, Магазины (закрывает issue 002)`

## Шпаргалка исполнителю

1. Конфигуратор → Справочники → Добавить → `Контрагенты`: вкладка **Данные** → «Иерархия справочника» = *Групп и элементов*; реквизиты `ИНН`, `Телефон`.
2. Добавить `Склады` (без иерархии).
3. Добавить `Магазины`: реквизиты `Адрес` и `Склад`. **Внимание, урок из issue 001:** тип `Склад` выбирается кнопкой `...` → ветка **СправочникСсылка** → галка `Склады`. Ссылочный тип — так же, как перечисление.
4. **Ctrl+S → Да**, затем **F5** (Предприятие): создайте группы и элементы Контрагентов (группа создаётся кнопкой с жёлтой папкой в списке), 2 склада, 2 магазина.
5. Закройте 1С, сообщите «готово» — приёмка по XML-выгрузке.
